# Patterns WooCommerce

Patterns WooCommerce is a sleek and flexible WordPress theme crafted for online stores, entrepreneurs, and businesses using WooCommerce. Powered by WordPress Full Site Editing (FSE), this block-based theme lets you easily customize headers, footers, templates, and global styles right in the Site Editor. It features pre-designed patterns and layouts ideal for showcasing products, featured collections, pricing tables, testimonials, team sections, about pages, shop categories, and contact forms. Includes layouts for product highlights, services, about, pricing, product grids, team, testimonials, contact page, and more. Fully responsive and optimized for performance, Patterns WooCommerce ensures your store looks professional and functions flawlessly on all devices—giving you a powerful platform to sell and grow online.

Primary color: `#FED700`.

## Features

- 3 hero and landing patterns
- 2 card layouts (card-1 through card-2)
- 1 pricing/plan pattern
- 9 archive/post-listing patterns
- Contact page pattern (page-contact)
- 1 menu navigation pattern
- 13 commerce patterns (cart, checkout, product listings)
- 16 section layout patterns (featured sections and section titles)
- Full Site Editing (FSE) support
- Responsive design
- 88 block patterns + 18 templates + 12 template parts
- WooCommerce support (templates, blocks, and product query patterns)

## Requirements

- WordPress 6.6 or higher
- PHP 7.0 or higher
- Tested up to WordPress 6.7

## Development

This theme uses `@wordpress/scripts`:

```sh
npm install
npm run start    # dev mode with watch
npm run build    # production build
```
